# Studio folder

This folder is built with the studio-builder plugin: the studio's rules and flows are learned from example projects. Reply to the designer in Ukrainian.

- Learn the rules with `/studio-builder:learn-studio`, a flow with `/studio-builder:new-flow`.
- Never touch the Google Drive folder directly. Read it only through `drive-gate`.
- Work only on copies inside `work/`. Never change originals.
- Example projects live in `work/examples/`. The designer copies them there, or `drive-gate fetch` does it. Many examples are welcome: count them in code (`sb-corpus`), do not read every dump yourself.
- Rules and flows are drafts until a person confirms them. Never mark one `confirmed` or `approved`.
- If something unexpected happens (a project with unsaved changes open in After Effects, a missing file), stop and ask.
