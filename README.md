# motion-flow

A universal Claude Code plugin for After Effects motion teams.

Pipeline: `intake → plan → build → check → deliver`. A human approves after `plan` and after `check`.

Status: scaffold (v0.1.0). Skills and tools are still in development.

Scripts (`bin/`, `hooks/`, `scripts/`) are Node.js (ESM, no external dependencies). Tests: `node --test`. Requires Node 18 or newer.
