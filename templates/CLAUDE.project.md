# Motion project

This project uses the motion-flow plugin. Reply to the designer in Ukrainian.

- Start every task with `/motion-flow:intake`.
- Never touch the Google Drive folder directly. Read it only through `drive-gate`.
- Work only on copies inside `work/`. Never change originals.
- Source files live in `work/`. The designer copies them there by hand, or `drive-gate fetch` does it when this project uses Drive folders. If a needed file is missing from `work/`, ask the designer to copy it there.
- Show the plan and wait for the designer's approval before any change.
- If something unexpected happens (missing file, broken links, mismatched hash), stop and ask.
- Run `/motion-flow:doctor` if a tool seems to be missing.
